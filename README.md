# Unity-Game-Mechanics

A collection of gameplay systems and mechanics I am building while learning Unity and C#.
This repository contains small systems and experiments focused on understanding how different game mechanics work.

## Current Mechanics

* WASD Player Movement
* Jump System
* Third Person Camera Follow
* Damage Dealer
* Idamagable
* Health System
* Enemy Patrolling System
* Mouse Sensitivity + Camera Controller
* Obstacle spawnner
* Safe Zone


## Future Work

More gameplay mechanics and systems will be added as I continue learning and experimenting with Unity and game development.
